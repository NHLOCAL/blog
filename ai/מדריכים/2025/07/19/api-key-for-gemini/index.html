מדריך: איך ליצור מפתח API לג'מיני בשלוש צעדים פשוטים

19/07/2025 קטגוריות: AI, מדריכים

מהו מפתח ה-API של ג’מיני ולמה זה טוב?

כמו כמעט כל דבר באינטרנט, ניתן להשתמש במודלים כמו ג’מיני או GPT, דרך ממשק המשתמש באתר שלהם. זה נוח ושימושי למדי לרוב האנשים, אבל לפעמים במיוחד במשימות קבועות שחוזרות על עצמם - יש יתרון משמעותי לשימוש במפתח API.

כלים רבים שיצרתי ושיצרו אחרים, כמו יוצר הפודקאסטים או יישומים אחרים, דורשים שימוש ב”מפתח API” כדי לפעול. למרות השם הטכני, מדובר ברכיב שכל אחד יכול להפיק ולהשתמש בו, ללא צורך בידע מוקדם בתכנות או אפילו באנגלית.

מפתח API הוא למעשה קוד זיהוי אישי. זהו רצף ייחודי של תווים המאפשר ליישום שבו אתם משתמשים לשלוח בקשות למודל הבינה המלאכותית של גוגל. המפתח מוודא שהבקשה מגיעה מכם ומאפשר לגוגל לנהל את השירות באופן מסודר ומאובטח.

המדריך הבא מפרט את השלבים הפשוטים הנדרשים להפקת מפתח כזה.

הפקת המפתח - שלב אחר שלב

התהליך כולו מתבצע בעמוד אחד בממשק של גוגל.

  1. היכנסו לעמוד ניהול המפתחות של Google AI Studio בקישור הבא:
    https://aistudio.google.com/apikey

  2. לחצו על הכפתור הכחול ”+ Create API key”, הנמצא בחלק העליון של העמוד.

  3. בחלון שייפתח, המערכת תבקש מכם לקשר את המפתח לפרויקט. בחרו באפשרות “Create API key in new project”.

  4. לאחר מספר שניות, המפתח החדש יופיע על המסך. העתיקו אותו באמצעות לחיצה על כפתור ההעתקה המופיע לידו.

את המפתח שהעתקתם ניתן כעת להדביק בכלי או בשירות שדורש אותו.

דגשים ונקודות חשובות

  • שמירה על סודיות: יש להתייחס למפתח ה-API כאל סיסמה אישית. אין לפרסם אותו במקומות פומביים או לשתף אותו. חשיפת המפתח עלולה לאפשר לאחרים לבצע פעולות דרך החשבון שלכם.

  • במקרה של חשיפה: אם המפתח נחשף בטעות, יש לחזור לעמוד ניהול המפתחות, לאתר את המפתח הרלוונטי, וללחוץ על סמל הפח שלידו. לאחר מכן, ניתן ליצור מפתח חדש באותה הדרך.

  • אחזור המפתח: אם תצטרכו את המפתח שוב בעתיד, תמיד תוכלו לחזור לעמוד ניהול המפתחות ולהעתיק אותו משם.

כעת, עם מפתח ה-API שהפקתם, תוכלו להשתמש בו בכלים הדורשים זאת, כמו אלו המוצעים בארגז הכלים שלי.
